# بازارچه مستقل — نسخه آغازین 0.1

بازارچه چندفروشنده‌ای دعوت‌محور، فارسی و راست‌چین؛ مناسب عرضه محصولات اعضا و افراد دعوت‌شده در شهرهای ایران.

## وضعیت این بسته
این بسته شامل یک نمونه اولیه قابل اجرا در مرورگر، طرح پایگاه داده D1 و اسکلت Worker است.
**هنوز نسخه عملیاتی/امن برای دریافت سفارش واقعی نیست.** قبل از استفاده واقعی باید API احراز هویت، کنترل دسترسی، بارگذاری امن رسید در R2، آزمون‌ها و تنظیمات Cloudflare تکمیل و بررسی شوند.

## اجرای نمونه رابط
فایل `public/index.html` را مستقیماً در مرورگر باز کنید. داده‌های نمایشی در مرورگر ذخیره می‌شوند و با پاک کردن Local Storage حذف خواهند شد. این نسخه به سرور یا حساب بانکی متصل نیست.

## معماری هدف
- Frontend: HTML/CSS/JavaScript ساده و قابل میزبانی روی Cloudflare Pages یا Workers Static Assets
- API: Cloudflare Workers
- Database: Cloudflare D1
- File storage: Supabase Storage؛ سطل `product-images` برای تصاویر محصول و سطل خصوصی `payment-receipts` برای رسیدها
- Cloudflare Worker به‌عنوان واسط امن بین D1 و Supabase Storage؛ کلید `service_role` فقط به‌صورت Secret در Worker
- Source control: GitHub

## نقش‌ها
- `admin`: مدیر بازارچه
- `seller`: فروشنده تأییدشده
- `buyer`: خریدار عضو یا دعوت‌شده
- دعوت‌نامه‌ها یک‌بارمصرف و دارای تاریخ انقضا هستند.

## قوانین مهم نسخه اول
1. پرداخت مستقیماً به حساب فروشنده انجام می‌شود.
2. رسید صرفاً مدرک ارسالی است؛ فروشنده باید تراکنش را در حساب بانکی خود بررسی کند.
3. شماره کارت/شبا در صفحه عمومی محصول نمایش داده نمی‌شود؛ فقط پس از ایجاد سفارش و برای خریدار همان سفارش.
4. تحویل فقط حضوری است؛ محل/زمان دقیق تحویل پس از هماهنگی فروشنده و خریدار تعیین می‌شود.
5. سفارش چندفروشنده‌ای در نسخه اول به سفارش‌های جداگانه برای هر فروشنده تبدیل می‌شود (در نمونه UI فعلاً جریان ساده‌سازی شده است).

## ساختار
- `public/`: نمونه رابط کاربری قابل مشاهده
- `migrations/0001_initial.sql`: ساختار اولیه D1
- `worker/`: اسکلت Cloudflare Worker و راهنمای اتصال امن به Supabase Storage
- `docs/SECURITY_AND_ROADMAP.md`: الزامات پیش از انتشار

## راه‌اندازی Cloudflare
پس از تکمیل API:
1. ساخت D1 database و اجرای migration
2. ساخت R2 bucket خصوصی
3. تعریف bindings در `wrangler.toml`
4. تنظیم secrets مانند `SESSION_SECRET`
5. اتصال مخزن GitHub به Cloudflare و استقرار
جزئیات تکمیل نشده‌اند؛ این بسته به‌تنهایی چیزی را در Cloudflare منتشر نمی‌کند.
